# K72 creative agency clone

A responsive React recreation of the K72 agency website, built with Vite,
Tailwind CSS and GSAP.

## Commands

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run lint` — run ESLint

The project gallery currently references public K72 case-study images. Download
and self-host licensed assets before deploying this project publicly.
